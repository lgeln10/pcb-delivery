# 平台品牌标识

把官方 SVG 按下面的文件名放进这个目录,「智能体管理 → 集成」的平台行就会自动用它;
文件不存在时回落到品牌色块 + 首字(见 `AiAgentIntegrationTab.vue` 的 `BRAND`)。

| 文件名 | 平台 | 去哪拿 |
|---|---|---|
| `feishu.svg` | 飞书 | 飞书开放平台的品牌/视觉规范 |
| `wecom.svg` | 企业微信 | 企业微信官方素材 |
| `dingtalk.svg` | 钉钉 | 钉钉开放平台「市场应用 LOGO 规范」 |

★**为什么不预置**:simple-icons(CC0)里只有消费版微信,企业微信 / 飞书 / 钉钉都没有;
  而这三家的标识各自有使用规范,凭记忆重画出来的一定走形 —— 走形的 logo 比没有更糟,
  而且是对外可见的商标使用。所以这里只留位置,由交付方按各平台规范取用后放入。

★放进来的文件应是**方形、单色或原色、去掉外边距**的 SVG;组件按 22×22 渲染。
