# C01 双面板·干净 — 网页验收清单

输入:`input/board.zip`(KiCad 5.99 导出的 Flashpads 测试板:F/B Cu、F/B Mask、F/B Paste、F/B Silk、Edge_Cuts、PTH/NPTH 两个钻孔文件;全部带 `%TF.FileFunction`)
预期:所有层高置信度识别、无 EQ、钻孔六项检查零 error、板型 = 双面正片。

前置:三个服务已起(`pcb-worker` / `aios-api` / `aios-web`),页面顶部显示「CAM 引擎在线」。

## 操作 → 勾选

- [ ] 1. 左侧「制造工程 → PCB CAM」能进入;空态显示「还没有 CAM 任务」+「新建项目」按钮
- [ ] 2. 新建项目:名称 `C01-Flashpads`,客户留空,工厂标准留空 → 创建成功,项目筛选自动选中它
- [ ] 3. 上传资料:只选 `board.zip` → 「上传并开始」→ 任务抽屉自动打开,状态「排队中」或「处理中」
- [ ] 4. ≤15s 内状态变为「待确认」,提示「请确认每个文件对应的层」
- [ ] 5. 层确认表 11 行;对照 `expected/layer_map.json`:每行 type 正确、置信度 ≥ 80%(绿色)、无「unknown」
- [ ] 6. 点「确认层识别,继续」→ 状态回到「处理中」→ 再次「待确认」,提示「请核对 AI 读出的制作规格」
- [ ] 7. 规格文本框:没有附件,所以是 `_note: 没有可读的制作要求附件…` 的空规格 → 直接「确认规格,继续」
- [ ] 8. 「步骤」tab:资料整理 ✓ 审单 ✓ 对齐/Profile ✓ 钻孔 ✓ 依次变「通过」;后续 stage 在 M1 显示「通过」(未实现占位)
- [ ] 9. 「检查报告」tab 选「钻孔」:对照 `expected/drill_table.md`,info 项里有每个刀具的预大记录(fix=已自动);error 数 = 0
- [ ] 10. 「层预览」tab 选 `Flashpads-F_Cu.gbr`:能看到板子铜面 SVG;切 `Flashpads-Edge_Cuts.gbr` 看到外形
- [ ] 11. 「流程单」tab:板型「双面板(普通喷锡/沉金工艺为例)」,类别「2、图形电镀加工流程(正片)」,p212;工序 14 步;叠层图 2 层;有一条警告(层数/规格相关,见 expected/mi_flow.md)
- [ ] 12. 「成果物」tab:至少有 `drill` 类型的预大钻带和 `dfm_report` 的孔表 JSON,点「下载」能保存
- [ ] 13. 「下载流程单」得到 HTML,浏览器打开能打印
- [ ] 14. 问题点:`eqTotal` 为 0(抽屉里没有「问题点决策」面板)
- [ ] 15. 列表页刷新后该任务状态「已完成」

## 不应出现

- 任何 `severity=error` 的报告项
- 「层识别未确认」「还有问题点没有决策」之类的报错
- 引擎离线提示
