## 第一章 入门基础（p3–23）

**目的逻辑**：建立 CAM 工程的背景框架 —— PCB 从接单到包装的整条生产流程、工程部各组（MI/CAM/E-TEST/光绘/检查）的分工、行业术语、Genesis2000 的定位（CAM 而非 CAD）以及 Gerber 数据格式的来龙去脉。本章是知识铺垫，不含操作步骤；后续第 4–17 章的每一步（预大钻嘴、补偿线宽、输出菲林/钻带/锣带）都以本章"为生产各工序提供工具"的定位为依据 (p15)。

**内容要点**：
1. **PCB 基本流程**（p3）：市场接单 → 工程处理资料 → 编写流程：1.开料 → 2 内层线路（蚀刻）→ 3 内层AOI → 4 压合 → 5 钻孔 → 6 沉铜 板电 → 7 线路图形转移 → 8 图形电镀 → 9 褪干膜蚀刻 → 10 线路AOI → 11 阻焊 → 12 字符 → 13 表面处理 → 14 成型 → 15 测试 → 16 FQC → 17 包装。注意：每个工厂机器设备及采用的技术不同，流程有所不同 (p3)。【人工（厂规确认）】
2. **工程部工具分工**（p4）：
   - MI组\QAE：检查客户资料完整性、可制作性（与本厂能力一致，有疑问及时问客确认）；编写工艺流程、基本制作要求、拼板、开料图、成型图 (p4)。【人工 + AI判断】
   - CAM：依据 MI 要求对客户 gerber 资料用 PCB 软件优化处理（内层、钻孔、外层线路、阻焊、字符、外形等），重点用 genesis2000 (p4)。【脚本 + AI判断】
   - E-TEST 组：制作测试程式；光绘组：用光绘机读入光绘文件绘出菲林；检查组\QAE：检查所有菲林、钻孔程式、成型程式与 MI 要求是否一致 (p4)。【人工】
3. **工艺流程（多层简单正片为例）**（p4–5）：
   - 开料：一张大料开成几张小板，常用大料尺寸 41*49INCH、43*49INCH、37*49INCH (p4)。
   - 内层：磨板 → 辘油或贴膜（二选一）→ 曝光 → 显影 → 蚀刻/去膜 → 内层AOI检测（蚀刻不净、蚀刻过度、线幼、开路、短路）→ 黑化（棕化）→ 层压（四层板压合结构：铜箔 PP 内芯 PP 铜箔）(p4–5)。
   - 钻孔：为各层线路连接而钻孔，后续电镀使孔壁镀铜；还有螺丝孔、定位孔、排孔等 (p5)。
   - 沉铜/板电：沉铜在孔壁沉积 0.3-0.5UM 铜使孔壁导电（化学镀铜、孔化）；板电加厚孔内镀铜层 (p5)。
   - 线路图形转移 → 图形电镀（加大线路和孔内铜厚，主要是孔铜厚度）→ 褪膜蚀刻（温度 45+5；药液成分：氯化铜、双氧水、盐酸、软水）→ 线路AOI → 阻焊、字符、表面处理、测试、成型、FQC、出货 (p5)。
4. **PCB 专业术语表**（p6–14）：五大类共 367 条中英对照 —— 一、综合词汇 82 条 (p6–7)；二、基材 51 条 (p8–9)；三、基材的材料 104 条 (p10–11)；四、设计 78 条 (p12–13)；五、形状与尺寸 52 条 (p14)。已全量提取到 knowledge/glossary.json。【脚本（术语查询）】
5. **Genesis2000 简介**（p15–16）：
   - 由以色列 Orbotech 与 Valor 合资的 Frontline 公司开发；允许用户自行开发适合自己规范的功能 (p15)。
   - 与 CAM350、V2000、GC-CAM、U-CAM、ParCAM 相比：功能更强（能自动修正许多错误）、更好学、操作更简单直观 (p15)。
   - 培训定位：不是教设计线路板，而是把客户设计的板根据厂里机器能力用 Genesis2000 处理后，为生产各工序提供工具（各种菲林、钻带、锣带等）—— 学的是 CAM 范围，不属于 CAD 范围 (p15)。
   - CAM 的作用示例：客户要求钻 40mil，因后续工序孔壁加铜、成品会小于 40mil，故把孔加大后再输出厂里钻机能读懂的文件 (p15)。—— 这是第五章"孔径预大"的原理依据。【AI判断】
   - CAM 文件的应用：制作菲林（内层、外层、防焊、文字菲林）；光绘文件由 Genesis2000 输出，光绘机据此绘出菲林 (p15)。
   - 功能体现：D-code 及 Gerber 自动输入；原稿 Net list 与工作片 Net list 比较；On line DRC；分析检查（PWR GND 断短路、钻孔/焊垫/防焊遗漏、焊垫超出防焊面、文字或防焊沾到焊垫）；制程误差自动补偿；特性阻抗自动计算；CAM 工作流程程序化；编写 DFM 自动化程式（SCRIPTS）(p16)。【脚本】
   - 进阶内容：CAM 文件（钻带、锣带、Gerber）源代码解析；ERF 文件修改；Hook 程序编写；Script 程序基础 (p16)。【脚本】
6. **Gerber 文件概念**（p17–23）：
   - Gerber 是线路板行业描述各层图像及钻、铣数据的文档格式集合，是图像转换标准格式；最初由 Gerber 系统公司开发，现由 Ucamco 所有 (p17)。
   - 三个版本：Gerber X2（最新，可插入层叠信息及属性）；扩展 Gerber RS-274X（普遍使用）；标准 Gerber RS-274D（老版本，逐渐被废弃）(p18)。
   - RS-274X：二维矢量图像描述格式，可读 ASCII，包含控制码和坐标，元素是画好外形的线和 flash，正负性图形可组合 (p18)；aperture 整合在 gerber file 中，不需要 aperture 文件（内含 D 码）；铜皮不需像 RS-274-D 那样指定为"填充块"或"填充线"(p20)。格式例子见 p19。
   - RS-274-D：源自 EIA RS-274-D 数控标准，用于控制矢量光绘机；只含控制码及 X,Y 坐标，不含坐标单位及 Aperture 信息，需另配 Aperture 文件（wheel 文件），且 Aperture 文件没有标准，制造人员须手工输入 CAM 系统 (p20–21)；只支持简单图像操作，需用 stroking（填充块/填充线）构造复杂图形；已过时 (p21)。格式例子见 p20。
   - Gerber 格式的应用：由 EDA/CAD 软件产生，送到 PCB 工厂导入 CAM 软件为每道工艺提供数据；也可描述钻孔信息（Aperture 为 flash），但钻孔资料通常使用 Excellon 格式 (p21)。
   - 质量问题：部分 CAD 输出的 RS-274X 含语法/语义错误、精度太低造成舍入误差（Gerber 导出精度通常至少比 CAD 高 10 倍）、仍用填充块而非外形填充（应废弃）(p21)。【AI判断（导入资料时识别）】
   - 层别标识：RS-274X 不标明文档所属层别，靠文件名标明层功能、扩展名标格式（如 .GE）；有的设计者用模糊文件名或误用扩展名（如 .BOT）表达层功能，制造人员须打开文档查明 (p21)。—— 第四章"文件/层命名"要处理的就是这个问题。【AI判断 + 人工】
   - 为何由设计者转 GERBER 交 PCB 厂：避免 PCB 厂对 PCB 文件理解不同（如元件参数被留在成品上）、保护设计成果和公司机密；用免费软件 Viewmate V6.3 导入 GERBER 和 D 码文件检查正确性；钻孔数据一般为 Excellon 格式 (p22)。
   - 历史沿革：1980-08-27 Gerber 公司首次推出 Gerber 格式；1986 扩展支持尺寸可变 Aperture（已停用）；1991-04-26 扩展支持多边形和大量参数（AT&T 推动）；1993-01-31 出版最新版参考书；1997 被 Barco Graphics 收购，1998-09-21 出版《RS-274X 格式用户指导》，PCB 部门命名为 Ucamco；2010-12 用户指导更新到 G 版 (p23)。

**关键规则/经验**：
- 每个工厂机器设备及采用技术不同，流程有所不同 —— 流程/参数需按厂规 (p3)。
- 客户资料有疑问及时问客确认 (p4)。
- 开料常用大料尺寸：41*49INCH、43*49INCH、37*49INCH (p4)。
- 沉铜厚度 0.3-0.5UM (p5)；蚀刻温度 45+5 (p5)。
- CAM 处理钻孔须把孔加大后再输出，因后续工序孔壁加铜使成品孔径变小 (p15)。
- 内层正片/负片、删独立 PAD 等操作只做 CAM 不做 CAD 设计 —— 培训范围是 CAM，不是 CAD (p15)。
- 优先使用 RS-274X；RS-274-D 需配 Aperture/wheel 文件且无标准，已过时 (p20–21)。
- 钻孔资料通常使用 Excellon 格式 (p21–22)。
- 填充块（stroking）不会使文件无效，但处理时间更长、难度更大 (p21)。

## 第二章 gensis2000菜单工具栏操作及功能（p24–66）

**目的逻辑**：本章是 Genesis2000 的工具入门——先建立中英文菜单对照（p24–26），再走一遍安装/登录（p27–34）、系统菜单与图形编辑界面各菜单的功能注解（p35–52），最后落到 CAM 工程的第一道实操：把客户 gerber 资料读入 Genesis2000，并把"自动识别"识别错的格式参数（数位、单位、补零方式）和 D 码（Wheel）修正过来（p53–66）。读入正确是后续所有章节的前提；本章的判读逻辑（看 ASCII 原始代码 → 猜数位/单位/补零 → 改 Parameters → 看图确认）是最典型的"AI 判读 + 脚本执行"场景。

**执行步骤**：

一、安装与登录（p27–34）
1. 解压 genesis2000 压缩包到 E 盘，双击 install.bat，按 2、3、4、5 顺序点击，选择 "Server"，手动输入安装路径 D:/genesis/ (p27)【人工】
2. 点击 "Start"，一路 acept OK (p28)；驱动安装选 32 位，失败没有关系 (p29)；license 点 yes，报错点 OK (p29)【人工】
3. 用户名、密码、工作组可全部设为 1 (p30)；set logical databases 点 yes → Apply → Quit (p30)【人工】
4. 回到安装文件夹装 Xmanager：一直 next 到 finish，重启电脑 (p31–33)；把 D:/genesis/e97/get 下的 get.exe、gfx.exe 及 XMANAGER.EXE 发送到桌面快捷方式 (p33)【人工】
5. 使用：先点桌面 Xmanager，再点 get.exe，输入用户名、密码回车进入系统界面 (p34)【脚本】

二、菜单功能认知（p35–52，均为截图注解，操作要点如下）
1. 系统界面四个菜单：File / Actions / Options / Windows (p35)；工作料号（Job）内图标：matrix、steps、symbols、wheels、input、output 等 (p36)
2. Input 读入资料窗口右键菜单：View Graphic 看图、View Ascii 看原始代码、Parameters 调参数、Open wheel template 打开 D 码学习器 (p36–37)
3. 层次特性 matrix：层命名、层排序、定义层属性、备份层、备份 Step；四层板常规命名 GTO/GTS/GTL/L2/L3/GBL/GBS/GBO；正确命名是自动排序的前提，命名规则各厂不同 (p41)【脚本，命名规则厂规化】
4. 图形编辑界面：File / EDIT（Reshape 子菜单、Transform ALT+T 镜相旋转缩放）/ Actions（网络分析为特色功能）/ Options / Analysis / DFM（Cleanup 线转 PAD、NFP Removal 删独立 PAD、Pad Snapping 拉 PAD、Optimization、Solder Mask Repair）/ Step（S&R Edit 拼板编辑器、Table 手动拼板、Automatic 自动拼板）/ Output (p43–52)

三、gerber 资料输入（p53–66）
1. 一般流程：登入 → 建立工作料号 → 调入客户 gerber 资料 → 自动识别 → 检查并纠正错误 → 转换 (p53)【脚本】
2. 建立工作料号（每个工厂命名不一样），点击料号进入，点 input 打开读入窗口，设资料来源路径与目的地 (p54–55)【脚本】
3. 点击 Identify 自动识别；识别后检查无误再点 Translate 转换 (p55)【脚本 + AI判断】
4. 读入要处理的对象只有三种：Gerber 文件（Format 为 Gerber 或 Gerber274X）、钻孔文件（Excellon2）、D 码文件（Wheel），其他文件都不用管；274X 自身包含 D 码文件，274D 没有 (p56–57)【脚本按 Format 分类】
5. Gerber 文件检查：右键 View Graphic 看图象是否正确；不正确则右键 View Ascii 看原始代码，判断①数位（以最多位数为标准）②单位③补零方式 (p57–58)【AI判断】
   - 判读示例：G01X1001500Y954500D02* 两个字母之间最多七位 → 小数点前两位或三位 → 2:5 或 3:4 制（p37 写作 2:4 或 3:5）；确定小数点位置后知道实际大小，由实际大小猜单位；零加在后面是后补零（补零和省零是不同的意思） (p37, p58)【AI判断】
6. 右键 Parameters 修正参数；排查顺序：先补零方式和数位，再考虑单位，最后才查 D 码文件 (p38, p59)【脚本执行 + AI判断】
7. D 码问题处理 (p60–63)：
   - 缺少 Wheel 文件：读入列表没有 Wheel，找 ASCII 文件看代码，与 "LINE 40 D119 / CIRCLE 25 D79" 类似格式的可转为 Wheel；列表中有 Wheel 则在参数栏直接指定 (p60)【AI判断 + 脚本】
   - Wheel 文件出错：找到对应 Wheel 文件右击 Open wheel template 打开 D 码学习器 (p60)【人工】
   - 自建 D 码 6 步：1> File→Create；2> Params→Global 设 Wheel type（Gerber/Tools）、Units（Inch/mm/mil）、Dcode numbering（Explicit/Standard/Station/Order1/Order4/Order10）；3> Params→Conditional Units（可有可无）；4> Params→headline 选典型表头行 Add；5> Params→Table title / Table terminator 设开始、结束位置（一般只设开始）；6> 添加识别规则：选未识别 D 码 → EDIT→Add record → 下拉单选正确图形 → 按右边数值配识别规则 → Actions→Translate Wheel，重复 A–E 直到全部识别 (p39, p61–63)【人工 + AI辅助】
   - 正确识别完后一定要存盘退出；实在不行可用 CAM350 识别有问题的 gerber 再输出正确的 (p63)【人工】
8. Excellon2 钻孔文件处理：View graphic 看到不同大小的孔挨在一起即错误 → View Ascii 看代码（示例：前补零、数值最少五位）→ 对比当前参数（用了后补零 lead）→ Parameters 改正 → 再看图确认 (p64–65)【AI判断 + 脚本】
   - 改补零方式仍不正常则调小数点位置：2:3 改 1:4\3:2\4:1 等组合，使物件图象随坐标值增减而移动位置；再不行调单位；再不行查其 D 码文件 (p66)【AI判断】
   - 以上都解决不了则不处理钻孔文件，后面用分孔图转出钻孔文件；代码或 lst 文件中有刀的大小和个数的，参考分孔表直接在钻孔管理器里输入 (p66)【人工】
9. 点击 Translate，框住处显示 OK 表示资料已读入 genesis2000，资料输入完成 (p66)【脚本】

**关键规则/经验**：
- 三类文件的 Format 对应：Gerber/Gerber274X、Excellon2、Wheel；其他文件不用管 (p56)
- 判读原始代码的三个信息：数位（以最多位数为标准）、单位、补零方式；"补零"与"省零"一字之差意思不同 (p37, p58)
- 参数修正顺序：补零方式 → 数位 → 单位 → D 码文件 (p38, p59, p66)
- 钻孔文件解决不了可以先不管，后面用分孔图转出 (p57, p66)
- 层命名规则各厂不同，正确命名是自动排序的前提 (p41)
- 自建 D 码后一定要存盘退出；更详细内容见《Genesis2000基础培训教程》P35–P45 (p63)

## 第三章 常见几种转gerber软件（p67–109）

**目的逻辑**：客户给的不一定是 gerber，可能是设计软件原稿（PADS 的 .PCB/.ASC，DXP/AD 的 .PCB/.PCBdoc，Protel 99 SE 的 .DDB/.PCB，CAM350 的 .CAM）。CAM 要用对应软件把原稿转成 gerber（或 ODB++）后再读入 Genesis2000。转出过程的共性风险：零点没设好导致分孔图表进入单元、敷铜方式选错、负片当正片转、字符层参数错、软件版本不兼容、外形/槽孔被锁住转不出来。所以每种软件的流程都是"打开 → 设零点（右下角）→ 放分孔图 legend → 定义各层 → 输出 gerber + 钻孔 → 与原稿对照"。

**执行步骤**：

一、PADS（p67–81）
1. .PCB 文件直接点击打开 (p67)【脚本】
2. 设计零点：不设零点分孔图表格会进入单元里面，不好对孔数及属性，容易导致板子做错；一般零点设计在右下角 (p68)【脚本 + 人工核对】
3. 敷铜设计：灌注、填充用于线路正片，平面链接用于内层负片；客户没提供敷铜方式时，用两种方式各转一次作比较，有不同要与客户确认 (p69)【AI判断 + 人工问客】
4. 定义层：点击 cam；cam 文档中已有文件名先删掉再添加 (p70–71)【脚本】
   - 线路正片：文档类型选布线/分割平面，选层 top，输入文档名称，点"层"看设计参数；一般 2D 线不能勾；底层步骤相同 (p72)【脚本】
   - 内层负片：文档类型选 CAM 平面，点"层"看参数、预览选择看图形——很容易把负片当正片转出来 (p73)【脚本 + AI判断】
   - 字符层：文档类型选字符，点"层"看参数，勾起来的一般都是要的；字符参数一定要对 (p74)【脚本 + 人工核对】
   - 助焊层（贴片层）(p75)、阻焊层 (p76)、分孔图 (p77)、钻孔层 (p78)【脚本】
5. 输出：cam 文档中文件全部选中，cam 目录选导出目录，点运行 (p79)【脚本】
6. .ASC 格式：文件→导入，选中文件打开即导入 PADS，后续同上 (p80)【脚本】
7. 常见错误与解法 (p81)【AI判断】：

## 第五章 钻孔制作（p113–118）

**目的逻辑**：钻孔是层间连接的物理基础；孔径要做"预大补偿"，因为后续沉铜/电镀会使孔径收缩（钻嘴孔径 = 成品孔径 + 补偿量）。

**执行步骤**：
1. **核对资料**：对客户分孔图核对孔径、孔数；分孔图有而钻孔层没有的孔补到钻孔层；外形层上能用钻孔钻出的槽孔复制到钻孔层。槽孔绝对不能漏【AI判断 + 人工复核】
2. **定义孔属性**（Edit→Attributes）：Plated（默认）/ non_plated / via 三类；有疑问问客确认【脚本 + 人工（疑问件）】
3. **孔径预大**（Drill Tools Manager 填实际钻嘴）：
   - Plated 预大 0.15mm；NPTH 预大 0.05mm；Via 不预大【脚本，规则固定】
4. **钻孔检查**（Analysis→Drill Checks）：Hole Size / Extra Holes（不属于任何 Pad 的多余孔）/ Hole Separation（重复孔、接触孔、太近孔）/ Power-Ground Shorts / Missing Holes / NPTH to Rout【脚本执行 + AI判读报告】
5. **输出**：拼好生产 panel 后经 Auto Drill Manager 输出（教材注明"现在工厂一般都是用脚本输出"）【脚本】

**关键经验**：短槽、近孔相交孔、倒角孔、除披峰孔的处理各厂规则不同 → 需厂规知识库【AI判断，规则库化】

## 第六章 内层制作（p119–134）

**目的逻辑**：一切围绕蚀刻/电镀/层压的工艺窗口 —— 补偿蚀刻损耗、保证令环与间距、预防蚀刻缺陷、防层间短路，最后用网络比较保证电气一致性。分**负片**（地电层）和**正片**（信号层）两条流程。

### 负片流程（地电层，图形极性反转）
1. 做够散热 PAD —— ths/thr 编码（外径×内径×角度×开口数×开口长），孔边到内圆 ≥8mil、内外圆间 ≥8mil、开口 ≥8mil 且至少 2 个【脚本批量改 + AI判断例外】
2. 做够隔离 PAD —— 令环单边 ≥10mil【脚本】
3. 分区线 ≥10mil【脚本检测】
4. NPTH 孔削铜 —— 令环单边 ≥12mil（复制 NPTH 孔到影响层，正极性、Resize 加大）【脚本】
5. 削外围 —— 外围线 Change Symbol 加大到位（如 r40），对比确认不削掉有用物件后复制到各层（负片用正极性）【脚本 + AI判断（是否削到有用物件）】
6. 检测并修正【脚本 + AI判读】

### 正片流程（信号层）
1. **删独立 PAD**（DFM→NFP Removal）—— 独立 Pad 不影响电气连通，删除提高性能。⚠️ 仅内层正片可用，不可用于外层【脚本】
2. **转 Surface** —— 大铜皮 Contourize（无大铜皮可省）【脚本】
3. **线路补偿** —— <15mil 线路整体 Resize +1mil（蚀刻补偿）；阻抗线按设计值加大【脚本，参数由厂规+客户要求决定 → AI选参】
4. **信号层优化**（DFM→Signal Layer Optimization）：PTH 令环 Min7/Opt8、Via Min3/Opt6、Spacing Min/Opt 4、Drill to Cu 10，修正方式选 PadUp+Shave。
   **老师傅技巧**：先把最小间距设 0.1 优化（让 Pad 尽量加大），再设回 4 二次优化【脚本策略化】
   报告项（ARG Violation、Spacing Violation、H2Cu Violation、Pad Enlarge>limit、Same Net Space 等）中"系统无法自动修补"的 → 手动修【AI判读分类 + 人工修图】
5. **加泪滴**（Advanced Teardrops Creation）—— 防钻偏断连、防蚀刻藏异物；参数与优化参数联动（AR Min = 优化 Opt 值+1 等）【脚本】
6. **NPTH 孔削铜** —— 正片用负极性复制【脚本】
7. **填小间隙/锐角**（DFM→Sliver & Acute Angle）—— 防蚀刻缺陷【脚本】
8. **削外围** —— 正片须转负极性削【脚本】
9. **检测**（Signal Layer Checks，参数比优化时略放大以全量暴露）→ 按报告手动修改【脚本 + AI判读 + 人工】

### 收尾（负正片通用）
- **网络分析比较两次**：第一次正常比较；第二次减铜（铜皮缩小约 0.15mm）再比较，检查是否存在 <0.15mm 连铜线导致的潜在开路【脚本 + AI判读，异常人工确认】
- **掏铜**：大铜皮边距不足时掏铜皮，时机在"转 Surface 和补偿之后、优化之前"；选铜皮（Select Drawn）常需手动排除误选【AI辅助选择 + 人工确认】。
  （修订：原稿无"掏铜不能掏断连铜线导致短路"的说法，此句为归纳时误加，已删。原文 p130 讲的是网络比较第二次减铜 0.15MM 后检查是否有 <0.15MM 连铜线导致**开路**，见上一条；"V-CUT 位掏铜不掏断线"出自第七章 p139。）

## 第七章 外层制作（p135–139）

**目的逻辑**：外层比内层多两个概念 —— **SMD 焊盘**（无孔对应、纯贴片）和**与阻焊层的耦合**（开窗对应的物件必须是 PAD）。前提：删外围及板外物，以钻孔为基准校正 PAD。

**执行步骤**：
1. **转绿油 PAD**（DFM→Construct Pads by Reference，Tolerance 填同类物件之间的大小差别数值，如 1 或 1.5）
   （注：原文 p135 的 "如1或1.5" 是举例，不是固定范围 1–1.5。）—— 手动转，转完检查【脚本 + AI核查】
2. **转线路 PAD**（Construct Pads Auto, All Angles）—— 以已转好的防焊层为参考，Tolerance/Minimum/Maximum 过滤误判；每次只转一层，转完检查。⚠️ 不能把线转成 PAD【脚本 + AI核查】
3. **设 SMD 属性**（Set SMD Attribute, ERF=Non Drilled）—— 目的是防止后续优化乱改贴片盘；光学点、BGA 圆形 PAD 自动设置无效，需手动添加【脚本 + 人工/AI补漏】
4. **转 Surface**（大铜皮）【脚本】
5. **加大线路和 SMD PAD** —— 补偿 +1mil；未达 MI 最小线宽的直接改到最小值；**电金板线路不预大**【脚本，AI按板型选规则】
6. **掏铜皮**（同内层）【AI辅助 + 人工确认】
7. **信号层优化** + 按报告手动修改【脚本 + AI判读 + 人工】
8. **NPTH 削铜、移线**，保证线路/铜皮/焊盘距外形足够【脚本 + 人工例外】
9. **检测 + 对原稿网络分析**【脚本 + AI判读】

**关键经验**：同一网络的极小间隙要填实方便生产；独立线、独立 PAD 在正常补偿基础上再多补一点；V-CUT 位注意掏铜不掏断线。

## 第八章 阻焊制作（p140–144）

**目的逻辑**：阻焊的核心矛盾是"开窗要够大（露出焊盘可焊）" vs "盖线位要够（不露线路防短路）"。前提：开窗必须是 PAD，且开窗 PAD > 对应线路 PAD。

**基本规则**：
- 开窗及盖线位 ≥2mil；NPTH 开窗比孔单边大 0.1mm
- 过孔盖油；≥0.6mm 过孔盖油需加挡点；塞孔过孔 ≤0.5mm；铝片/树脂塞孔要做塞孔钻带（比孔径大 0.1–0.15mm）
- 金手指位开通窗；阻抗及 V-CUT 测试点开窗
- 阻焊桥：客户设计有桥必须做；白油黑油 5–6mil，杂油 ≥4mil，绿油最小可 3mil，做不到要提出

**执行步骤**：
1. 检查开窗对应线路是否为 PAD —— 不是则**外层返工**（依赖倒查）【脚本检测】
2. 绿油层全转 PAD（Features Histogram 找非 PAD 物件 → Construct Pads by Reference）【脚本 + AI核查】
3. 开窗比线路 PAD 大 —— 不够则整层 Resize Global【脚本】
4. **阻焊优化**（DFM→Solder Mask Optimization）：设开窗 Min/Opt、盖线位、阻焊桥参数。
   ⚠️ **只优化一次** —— 教材明确警告"连续重复优化会把 IC 引脚的贴片 PAD 开窗乱形"【脚本，硬约束】
5. 检测分析：Drill / Pads（含 Gasket 重叠）/ Coverage（盖线不足）/ Spacing / Missing（丢失开窗）/ Bridge（不同网络焊盘无桥）/ Sliver / Rout【脚本 + AI判读】
6. NPTH 及 ≥0.6mm 过孔盖油加挡点【脚本】
7. 对客户制作要求核查特殊项【AI判读 + 人工】
8. **对原稿** —— 检查是否改变了客户原稿设计，"这一步很关键"【脚本比对 + 人工放行】

**关键经验**：客户给 gerber 按 gerber 做，给设计稿按过孔盖油做；贴片层/测试点层要对开窗，不同需提出确认；金属包边及半孔部分阻焊须开窗防油墨进入；光标点大开窗一般按原稿不缩小（注：原文 p144 有例外——与铜皮相切或少许上大铜皮时可以缩小开窗，保证不上大铜皮）。

## 第九章 字符制作（p145–147）

**目的逻辑**：可读性 + 不污染焊盘。前提：与线路/阻焊/钻孔对齐，删板外物及外形线。

**规则**：字宽 ≥5mil，字高 ≥30mil，高宽比 ≥6:1；字符不能上阻焊开窗，距开窗 ≥3mil；可上大铜皮开窗但须先表面处理后印字。

**执行步骤**：
1. 做够字宽字高 —— 物件查看器选出不达标的线，直接改尺寸或 Edit→Transform（Anchor+Scale，如 Y Scale 1.2）放大【脚本】
2. 检查字符是否超出板外【脚本】
3. 检查字符是否上阻焊开窗【脚本】
4. 用阻焊掏字符 —— 复制阻焊层、清负性元素、加大后以负性掏字【脚本】
5. 对客户要求（是否需添加字符等）【AI判读 + 人工】
6. 分析检查、对原稿【脚本 + AI判读】

**⚠️ 红线**：板外字符必须删掉，否则拼板时串入其它板导致整板报废。字符上大铜皮是否保留一般要与客户确认【人工】。

## 第十章 SET 及 panel 拼板（p148–155）

**目的逻辑**：材料利用率 + 生产定位 + 电镀均匀性（板边阻流块分流电流）。

## 第十二章 金手指板制作（p159–169）

**目的逻辑**：金手指是板边用于插拔连接的导电触片（内存条、显卡等所有信号经它传输，p159），必须兼具导电、耐磨、抗氧化、耐腐蚀 —— 纯金太软，所以电镀"硬金"（金的化合物）而不是黄金（p160）。CAM 侧的工作是把金手指区域按倒角/开窗/削铜/间距规则做对，电镀工艺本身由生产端控制。

**执行步骤**：
1. **识别金手指及其类型** —— 常规（齐平）/ 长短（不平整）/ 分段（间断）三类（p161）；表面处理为电镀镍金（3-50u"，仅局部镀）或整板沉金（常规 1u"，最高 3u"，耐磨要求不高时可选，成本低很多）（p160）【AI判断（从 gerber/MI 识别）+ 人工确认】
2. **倒角（斜边）** —— 金手指需要倒角，通常 45°，其他 20°、30°；斜边要求一般 30/45/60 度三种；设计没有倒角"则有问题"（p160, p169）【脚本检测 + 人工/问客】
3. **阻焊** —— 金手指做整块阻焊开窗（开通窗），PIN 不需要开钢网（p160, p169）【脚本】
4. **焊盘距离** —— 沉锡、沉银焊盘距手指顶端最小 14mil；建议焊盘（含过孔焊盘）距手指位 1mm 以上（p160）【脚本检测 + 人工反馈】
5. **表层不铺铜**（p160）【脚本检测】
6. **内层削铜** —— 内层所有层面做削铜，通常削铜宽度大 3mm；可半手指或整手指削铜（p160）【脚本 + AI判断（半/整）】
7. 生产端电镀流程（供理解，非 CAM 操作）：入板→微蚀→水洗→磨板→水洗→活化→水洗→镀镍→水洗→活化→水洗→镀金→金回收→水洗→烘干→出板（p161）；沉镍金流程见 p165【人工（生产）】

**关键规则/经验**：
- 电镀硬金为增加耐磨性（p160）；镀镍层作用是获得低应力镍层、防止金铜渗透，镀金层为耐磨的金钴合金（p162）。
- 镀镍/镀金/化学镍金常见不良（起泡起皮、针孔麻点、烧焦、颜色不良、漏镀、渗镀、甩金、甩镍、孔壁上金等）及原因/处理方法见 p163–169，属生产端问题库，可用于判读客诉与 MI 备注【AI判读】。
- 无电镍工艺窗口：PH 4.8-5.3、温度 80~90℃、次磷酸二氢钠约 30g/I（超过 35g/I 槽液分解）（p166）；无电金操作温度约 85℃（p168）。
- "孔壁上金"原因之一是 D/F 穿菲林（p169）—— 与 CAM 菲林资料相关，须避免。

## 第十三章 锣带及模冲制作（p170–175）

**目的逻辑**：把外形层转成成型设备可执行的锣带（刀具路径 + 补偿 + 速度），或在大批量/直角外形场景下改用模冲（模具冲压）。锣带核心是"外围线干净闭合 → 层属性正确 → 尺寸标注 → 定义 Chain（刀径/补偿/起刀点）"，模冲核心是"定位孔 + 防爆孔 + 标数 + 标方向"。

**执行步骤（锣带）**：一般流程：创建外围→整理外围线→层别特性转换→确认及标示尺寸→刀具及切割路线设定→锣带文件输出（p170 流程图）
1. **创建外形** —— 已有则不重建；选外框接触物件不多的层，选中外框 Edit→Copy Other Layer 取名 Rout，其他参数不设，删掉 Rout 层中不属于外围的物件（p170）【脚本 + AI判断（选源层、删杂物）】
2. **整理外围线** —— 接合不佳处重新接合，以 ARC 取代线段组成圆弧（p170）：
   - Edit→Reshape→Design To Rout：设最大分析缺口、最大接合缺口、平滑偏移误差（p171）【脚本，参数固定】
   - Rout→Connection 或 Edit→Connections（Alt__O）：选取圆弧模式/导角模式，设 R角（半径）角度，选两条边预览（p171）【脚本 + 人工（选边）】
3. **层别特性转换** —— Job Matrix 将 rout 层定义为 Board；Rout；Positive（p172）【脚本】
4. **确认及标示尺寸** —— Rout→Dimensions：指定起点/终点，取点模式 All/PS/pe，调整标示位置及图示字型大小；不可重复标示同一终点线段（p172）【脚本 + 人工核对】
5. **刀具及切割路线设定** —— Rout→Chains：设刀具及切割路线，加引导孔优化下刀及起刀点；Chain 记录可添加/修改/删除/合并/优化/加导引孔；补偿三种（左/右/不补偿）一般按右补偿；设锣刀大小、Router 机台速度、起始点和终点（p173）【脚本（厂规刀径/速度）+ AI判断（起刀点）】
6. **锣带输出** —— 与钻带输出一样（p174）【脚本】

**执行步骤（模冲）**：流程：创建外形→增加定位孔→加防爆孔→外形标数及标注模冲方向（p174）
1. 创建外形，已有则不重建（p174）【脚本】
2. 定位孔 —— 一般选四个非金属孔，定位孔一般 3.0、2.0、1.5MM 三种（p174）【脚本 + AI判断（选孔）】
3. 防爆孔 —— 一般在槽的两端或拐角处加孔或槽，防止爆板（p174）【脚本 + AI判断（位置）】
4. 外形标数 —— 转成 AUTOcad 格式在 AUTOCAD 里标数，方便生产及品质检查（p174）【脚本 + 人工】
5. 标注模冲方向 —— 模冲图上必须表明进板方向；模冲生产拼板一定要倒扣拼板，注意拼板方向（p174）【人工】

**关键规则/经验**：
- 模冲适用：单面板孔及外形复杂的板、FPC；大批量板；外形倒角要求直角、角度严、锣板无法成型的板（p175）【AI判断（选锣/冲）】
- 模冲优点：速度快，数量越多成本越低，精度正常水平，最适合批量生产（p175）。
- 锣带补偿默认右补偿（p173）；外围线必须以 ARC 替代折线段以得到圆弧（p170）。

## 第十四章 半孔板及金属包边制作（p176–184）

**目的逻辑**：半孔 = 金属化孔（槽）经二钻或外形切掉一半留在板边（p176）；金属包边 = 板边金属化（p182）。两者都是"先孔化/电镀、再切掉一部分"，CAM 关键是：切割处的线路层要掏铜、阻焊要加挡点防油墨入孔、槽宽/刀径要按规则、成型时铜皮不翘起。

### 第一节 半孔板
**执行步骤（半孔锣边工艺）**：
1. 建外形层 GKO1，只做半孔部分；锣槽宽度一般 1.6MM（p177）【脚本】
2. 线路层半孔部分掏单边 0.1MM，再用钻孔加挡点，比孔整体小 0.1MM（p178）【脚本】
3. 阻焊 GKO1 层加挡点防止油墨入半孔，一般比槽单边大 0.1MM（p179）【脚本】
4. 生产流程：外层线路设计→基本图形电铜→基本图形电锡→半孔处理（锣半孔）→褪膜→蚀刻（p180）

**执行步骤（半孔二钻工艺）**：
1. 在半孔两端加孔，先钻掉一点铜皮，防止成型时孔壁铜刺翘起、残留（p180）【脚本 + AI判断（加孔位置）】
2. 阻焊加比孔单边大 0.1MM 的挡点，防止油墨入孔（p180）【脚本】
3. 生产流程：外层线路设计→基本图形镀铜→基本图形镀锡→半孔处理（二钻）→褪膜→蚀刻（p181）

**关键规则/经验**：
- 最小半孔 0.5MM，孔与孔之间间距最小 0.4MM（p181）【脚本检测，不达标问客】
- 常见不良：拉丝、半孔形状异常、板边凸点、铜皮翻卷（p181 图表）—— 二钻工艺"先钻掉一点铜皮"即为防铜皮翻卷/残留（p180）。

### 第二节 金属包边板
**执行步骤**：
1. 判断客户需要金属化包边的区域 —— 信息来源为 gerber 及 gerber 之外的 PDF、TXT、DWG 说明（p182）【AI判断 + 人工确认】
2. 将需包边外形拷贝到 GKO2 层，做成封闭长槽；包边处要镀铜、铜厚有厚度，包边槽一定要补偿（p183）【脚本，补偿量按厂规】
3. 检查：焊环单边大 10mil 以上（防碎膜）；包边距附近焊盘至少 8mil 以上，不满足则更改并反馈客户确认（p183）【脚本检测 + 人工/问客】
4. 确认包边后内外层连接情况与层间连结方式，避免包边后短路；如存在镀孔菲林，包边按 PTH 槽处理要有盘；异形槽包边同孔一样填实并放大 4mil（p183）【脚本 + AI判断 + 人工】
5. 做好包边槽后判断包边的电气连接性（p183）【AI判断 + 人工】
6. 阻焊：金属包边槽阻焊一定要完整开窗（p183）【脚本】
7. 包边槽刀一般 1.6MM 或 2.0MM（p183）【脚本，厂规选值】

**关键规则/经验**：
- 生产流程两种（p183）：包边+半孔：钻孔→锣金属包边→沉铜→线路图形→图形电镀→锣半孔→褪膜→蚀刻；包边+二钻：…→图形电镀→二钻→褪膜→蚀刻。即包边槽在沉铜前先锣出，半孔/二钻在图形电镀后再做。
- 与第八章阻焊规则呼应：金属包边及半孔部分阻焊须开窗/加挡点防油墨进入（p179, p180, p183）。

## 第十五章 阻抗板的基础知识（p185–201）

**目的逻辑**：阻抗是交流信号在传输线上受到的阻碍（单位欧姆，p185），CAM 要做的不是"算出阻抗"本身，而是把客户要求的阻值反推成可生产的**线宽/线距/叠层参数**。核心矛盾：阻抗值由介质厚度 H、介电常数 Er、线宽 W、铜厚 T、线距 S、阻焊 C 共同决定（p185–186），而其中线宽、铜厚、阻焊厚度都会被蚀刻/电镀/印油工艺改变——所以要按厂内工艺常数（W1–W2 差值、表铜厚度、阻焊厚度）把设计值换算成 POLAR SI9000 的输入参数，再选对计算模式。

**执行步骤**：
1. **识别阻抗类型** —— 单端(线)、差分(动)、共面三类（p185）；共面阻抗的特征是信号线两侧 GND/VCC 等距包围（p185）【AI判断（从客户要求/叠层中识别）】
2. **确定叠层与参考层** —— 找出阻抗线所在层、相邻的 VCC/GND 参考层、介质厚度 H1/H2/H3 与介电常数 Er1/Er2/Er3（p187–189）；隔层参考时比对应模式多一到两层介质（p190、p193）【AI判断 + 人工（叠层由 MI/PE 给定）】
3. **选择 POLAR SI9000 计算模式**（p187–200）：
   - 单端：外层阻焊前 Surface Microstrip / 阻焊后 Coated Microstrip / 两参考层夹一线路层 Embedded Microstrip / 与外层相邻的第二线路层 Offset stripline / 两参考层夹两线路层 Offset stripline（p187–189）
   - 差分：对应的 Edge-coupled 系列（p190–193）；含线间填充树脂的模式当 REr=Er2 时结果相同，一般不用（p193）
   - 共面：按"蚀刻后/阻焊后"、"有无次外层参考 (with ground)"、"内层 embedded/offset"、"单线/Diff" 组合选 14 种之一（p194–200）【脚本（模式→参数映射表可规则库化） + AI判断（选模式）】
4. **填参数（厂内换算常数）**：
   - W1 线底宽 = W2 线面宽 + Δ：内层 HOZ +0.3 / 1OZ +0.5 / 2OZ +1.2 mil；外层 HOZ +0.8 / 1OZ +1.2 / 2OZ +1.6 mil（p185）
   - T1 铜厚：内层按基板铜厚 HOZ 15 / 1OZ 30 / 2OZ 65 UM；外层 = 铜箔+镀铜，按孔铜规格查表（底铜 HOZ：45/50/55 UM；底铜 1OZ：55/60/65 UM）（p186）
   - 阻焊：印一次 C1 30 / C2 12 / C3 30 UM，印两次 60 / 25 / 60 UM，CEr 按 3.4（p186）
   - 共面模式另需 D1（阻抗线与 GND/VCC 的距离）（p194）【脚本（查表填参）】
5. **计算并调整线宽/线距到目标阻值** —— 参照实例：4 层板 1.6MM，GTL&GBL 参考 L2&L3，单端 4.5mil→50 欧姆，差分 5.1mil/6mil→85 欧姆（p201）【脚本（SI9000 迭代） + AI判断（在客户允许范围内选线宽）】
6. **把结果回写到 CAM 补偿** —— 阻抗线按计算出的 W1 加大（与第六章"阻抗线按设计值加大"衔接）【脚本】

**关键规则/经验**：
- 各参数与阻抗的方向：Er、W、T、阻焊厚度、CEr 均**反比**；H（介质厚度）、S（差分线距）**正比**（p185–186）——调阻抗时优先动线宽，其次动介质厚度。
- 外层 T1 不是固定值，取决于孔铜要求（平均 20/最小 18、平均 25/最小 20、单点最小 25 UM 三档），做外层阻抗前先确认孔铜规格（p186）【AI判断】。
- 内层 T1 = 基板铜厚（无电镀）；外层 T1 = 基板铜厚 + 电镀铜厚（p187–189）。
- 差分模式必须多一个 S1（线间隙）参数；阻焊后差分模式多 C3（线间阻焊厚度）（p190–191）。
- 共面模式的"with ground"版本表示次外层也是 GND/VCC 参考层，没有则次外层是线路层（p194–195）——选错会算出不同结果，需要核对叠层。
- 隔层参考（参考层不相邻）时用同族模式的多介质层版本（2B / 2B2A）（p190、p193）。

## 第十六章 盲孔及HDI板（p202–211）

**目的逻辑**：HDI/盲埋孔板用小微孔换取布线空间、缩小 PCB 体积（p202）。它把"钻孔"从一次动作变成**多次压合 + 多次钻孔 + 多次电镀**的循环，CAM 的核心风险从"孔径对不对"变成"**哪个钻带对应哪两层**"——对错一层整板报废（p205–206）。工艺上又受激光（需 RCC 吸光材料、需先蚀 Cu Clearance）和电镀（每层只能 1 次板电 + 1 次图电）两个硬约束牵制（p202–203）。

**执行步骤**：

### 一、判断钻孔方式与工艺路线（工程前置）
1. 判断是否必须激光钻孔：客户要求 / 盲孔孔径 <=6MIL / 层间叠加的特殊盲埋孔（L1-L2 盲 + L2-L3 埋）（p202）；钻嘴 >=0.20mm 才可考虑机械钻（p203）【AI判断（规则固定）】
2. 激光板材料与菲林要求：用 RCC（无玻纤、吸光），RCC 介电常数偏小（S6018 为 3.8），有阻抗控制时注意（p202）；盲孔位先蚀出与完成孔径等大的 Cu Clearance；激光定位标记加在 L2/LN-1 层并在 MI 菲林修改页注明；蚀盲孔点菲林必须 LDI 制作、开料用 LDI 板材尺寸（p202）【脚本（Cu Clearance 生成、定位标记） + 人工（MI 注明）】
3. 电镀/贴膜方案（RD 通告 TSFMRD-113，p203–204）：
   - 前提：任何层只可 1 次板电 + 1 次图电；板厚 >=80MIL 时通孔需板电+图电，故盲孔电镀时外层不能板电
   - 外层线宽 >6MIL 且板厚 <80MIL → 外层可整板电镀；线宽 >6MIL 但板厚 >80MIL、或线宽 <6MIL 且板厚 >=80MIL → 外层贴膜保护
   - 贴膜方式：盲孔纵横比 L/D <=0.8 整板曝光；>0.8 盲孔曝光（需曝点菲林或 LDI）
   - 曝点方式：盲孔 <=0.4MM(16MIL) 用 LDI，>0.4MM 用菲林
   - 埋孔：埋孔面线宽 <=4MIL 贴膜曝点，>4MIL 直接板电
   - 曝光点直径 D=D-6 (MIL)，菲林加与外围参考孔一致的对位点；贴膜盲孔用脉冲电流【AI判断（分支条件） + 脚本（曝点菲林生成）】

### 二、工程资料处理（p205–207）
1. 解压客户资料到一个目录，检查制作要求与资料完整性（p205）【脚本 + AI判断】
2. 读入 genesis，按工厂要求命名（p205）【脚本】
3. **按客户钻层排列层叠顺序**（Job Matrix 中每个 drl 层对应正确的起止层）—— "这一步是关键，一定不能搞错"（p205）【脚本（矩阵设置） + 人工复核】
4. 按正常工程流程做资料，做完仔细检查，"如果工程资料错了整个板子就报废"（p206）【脚本 + AI判读 + 人工】
5. 根据钻孔与客户层叠确认压合结构图（例：12 层 HDI，PP 1080(0.08MM)、芯板 0.2MM 含铜 1/1OZ，压合厚度 1.5+/-0.1MM，成品 1.6MM+/-10%）（p206）【AI判断 + 人工（PE/RD 确认）】
6. 按叠层压合图编写生产流程单：开料→内层→一次压合(3-10)→钻孔 drl3-10→沉铜→树脂塞孔→线路→二次压合(2-11)→激光钻孔 drl2-3/10-11→沉铜→线路→三次压合(整板)→激光钻孔 drl1-2/11-12→沉铜→树脂塞孔→钻通孔→正常流程（p207）【脚本（流程模板） + 人工】

### 三、常见叠层结构（p207–211）
- 四层：1-2和3-4盲孔；1-2和3-4盲孔+2-3埋
- 六层：1-2,5-6,2-5 / 1-2和5-6 / 1-2;1-3;2-5;4-6;5-6 / 1-2;1-3;4-6;5-6
- 八层：1-2;7-8 / 1-2;2-7;7-8 / 1-2;3-4;5-6;7-8 / +1-4;5-8 / +2-7
- 十层：1-2;9-10 / 1-2;2-9;9-10 / +1-5;6-10
- 芯板/PP 及叠层"根据客户提供的资料来定"（p211）【AI判断（匹配模板） + 人工】

**关键规则/经验**：
- IPC-6016：激光盲孔孔壁铜厚 0.4mil(min)；焊锡圈允许相切，PAD 比孔径大 5mil 以下建议加 TEARDROP（p203）——与第六章泪滴步骤联动【脚本】。
- RCC 未过 UL 认证，此类板暂不加 UL 标记（p203）；MI 排板结构中 RCC 要与 L2/Ln-1 分开画，避免被当假层板（p203）【人工】。
- 板边 >=0.8"（多次压板、工艺孔多）（p203–204）——拼板时的边距参数【脚本】。
- 外层有盲孔：压板后必须加除胶；化学沉铜仅 0.05–0.1MIL 易被磨掉，须加板电镀加厚——工序为 压板—除胶—钻孔—沉铜—板电镀—干膜—图形电镀（p204）。
- 埋孔大且多时经 R&D 要求可压板前树脂预塞，参照绿油塞孔（p204）。
- PIN-LAM 只有 CORE <30MIL 才能打孔（p204）。
- 写 LOT 卡：副流程要写单个副流程排板结构，特别要求里再写主流程排板结构（p204）【人工】。
- 纵横比定义 L=介质厚+铜厚，D=盲/埋孔直径（p204）——可脚本计算并驱动贴膜分支。

## 第十七章 工艺流程单制作（p212–219）

**目的逻辑**：工艺流程单（MI 流程）是把板型特征翻译成**车间工序顺序**的文件。教材给出的不是一条流程而是一张"板型 → 工序链"映射表：正片/负片决定电镀方式（图形电镀 vs 整板电镀），特殊工艺（二钻、半孔、金属包边、光板叠层、盘中孔、电金、沉金、盲埋孔）在基础链上**插入或调换**个别工序，且插入位置由"下一道工序能否清理上一道的副作用"决定（如二钻毛刺要靠蚀刻去掉，p212）。

**执行步骤**：
1. **判定基础板型** —— 光板 / 单面板(含假双面) / 双面板 / 多层板（p212）【脚本（从层数、钻孔属性判定）】
2. **判定正片/负片** → 选基础链（p212）：
   - 正片（图形电镀）：开料→钻孔→沉铜/板电→图形转移→图形电镀→蚀刻/退锡→阻焊→字符→表面处理→成型→测试→终检→包装→入库出货
   - 负片（整板电镀）：开料→钻孔→沉铜→整板电镀→图形转移→蚀刻→阻焊→字符→表面处理→…
   - 多层板在开料后插入 内层线路→蚀刻→AOI测试→压合，钻孔后插入 除胶渣【脚本（模板选择）】
3. **按特殊工艺插入/调换工序**（p212–213）：
   - 二钻/锣半孔：正片插在图形电镀后、蚀刻/退锡前；负片插在字符后、表面处理前
   - 半孔、金属包边：都需做正片；金属包边在钻孔后插 金属包边
   - 叠层加光板（假八层负片）：开料后插 蚀刻成光板→钻铆钉孔
   - 盘中孔（负片）：前置 钻盘中孔→1次沉铜→1次整板电镀→树脂塞孔→打磨→减铜，再 开料→钻孔→2沉铜→2整板电镀…
   - 电金：图形电镀后插 镀金；电金+沉金再在字符后插 印选化油→沉镍金→退选化油【脚本（规则表） + AI判断（识别客户要求中的特殊工艺）】
4. **写备注参数**（p212–213）：开料板厚（双面板成品板厚减 0.1mm；铜厚减 H/HOZ；多层板看内层铜厚板厚）、图形电镀写电镀面积、光板/单面板不需电镀、电金菲林盖住其他位置、选化油菲林比焊盘大单边 2mil【脚本（计算） + 人工核对】
5. **盲埋孔板用序号表流程单**（p214–219）：按"开料→（钻埋孔→沉铜→整板电镀→树脂塞孔）→内层线路→蚀刻→测试→压合→铣毛边→激光钻孔→电镀填孔→…→钻孔→以下正常流程"循环展开，每次压合一轮；每行写制作要求（钻带层号、背光 9 级、工艺边 10/12mm）和备注（分清钻带避免钻错、L2 压 L3…）【脚本（按叠层生成序号表） + 人工（PE 确认叠层）】
6. **输出流程单 + 压合图** —— 表格与压合结构图（各层铜厚、PP 型号厚度、压合厚度/成品板厚公差）一并交付（p214–218）【脚本 + 人工放行】

**关键规则/经验**：
- **负片二钻不能放蚀刻前**：负片不镀锡，线路无保护会刮伤，所以二钻在表面处理前；正片二钻放蚀刻前，让蚀刻去掉毛刺（p212）——这是顺序型硬约束【脚本】。
- 光板/单面板/假双面：按成品铜厚开料，不做电镀（p212）。
- 叠层加光板：先开光板厚度的料、蚀刻成光板、再钻铆钉与靶孔，否则压合无法铆合（p213）。
- 盲埋孔流程单：内层成品铜厚 1/1oz 正常镀埋孔，H/Hoz 需开料后减铜至 1/3oz（p214、216）；四层盲孔（机械）GTL/GBL 做保护菲林、压合后减铜至 1/3OZ（p215）。
- 激光钻带必须分清层对（L1-L2 vs L3-L4 等），"避免钻错"在每张表重复出现（p214–219）——脚本生成钻带文件名时应显式带层号【脚本】。
- 二阶盲孔：一次压合 L2 压 L3、L5 压 L4，工艺边多加一套靶孔；二次压合 L1 压 L2、L6 压 L5（p216–217）。
- 工艺边控制：四层 10mm，六层 12mm（p214–218）。
- 板厚公差示例：压合厚度 1.5+/-0.1MM，成品 1.6MM+/-10%（p218）。
