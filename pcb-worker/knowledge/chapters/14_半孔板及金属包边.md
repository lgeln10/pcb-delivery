## 第一节：半孔板制作

### 一、半孔板定义

金属半孔（槽）是指一钻孔经孔化后再进行二钻、外形工艺，最终保留金属化孔（槽）一半，即板边金属化孔切一半。

2、工艺流程

#### 二）、半孔二钻工艺

1、在半孔两端加孔，先钻掉一点铜皮，防止在成型时孔壁铜刺翘起、残留。如图：

阻焊需要加比孔单边大0.1MM 挡点，防止油墨入孔

2、工艺流程

外层线路设计 → 基本图形镀铜 → 基本图形镀锡 → 半孔处理（二钻） → 褪膜 → 蚀刻.

### 三、半孔最小孔径能力

最小半孔为0.5MM 孔与孔之间间距最小0.4MM.

### 二、金属包边板子工程制作

1.需要判断客户需要金属化包边的区域；

包边信息的来源是gerber文件和gerber之外的PDF、TXT、DWG等里面的信息说明。

<!-- page:183 -->
2、金属包边电路板的线路制作及注意事项；

1）、将需要包边的外形拷贝到一层（命名为GKO2)，做成封闭的长槽。注意由于包边处需要镀铜，铜厚是有一定厚度的，制作时包边槽一定要补偿；

2）、包边的电路板为了防止碎膜，需保证焊环单边大10mil以上，包边距附近的焊盘至少要8mil以上，如果没有需要更改反馈给客户确认；包边后一定要内外层连接情况，确认层间连结方式，避免包边后引起短路。如存在镀孔菲林，包边制作必须按PTH槽一样处理，要有盘，特别留意异形槽的包边也应该与孔一样，需要做填实并放大4mil.

3、做好包边槽之后，接下来要判断包边的电气连接性；

4、金属包边电路板阻焊制作及注意事项

金属包边槽阻焊一定要完整开窗

5、金属包边槽刀

一般采用1.6MM或2.0MM

### 三、金属包边流程

1、金属包边+半孔工艺

钻孔 → 锣金属包边 → 沉铜 → 线路图形 → 图形电镀 → 锣半孔 → 褪膜 → 蚀刻

2、金属包边+二钻工艺

钻孔 → 锣金属包边 → 沉铜 → 线路图形 → 图形电镀 → 二钻 → 褪膜 → 蚀刻
