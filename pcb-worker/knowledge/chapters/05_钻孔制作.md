### 一、核对资料

根据客户提供信息或分孔图核对孔径大小及孔数看是否一致，有疑问需要提出来

把分孔图上有孔钻孔没有的复制到钻孔层

将外形上能用钻孔钻出来的复制到钻孔层钻出来

需要特别注意的是分孔图及外形层上的槽孔不能漏，一定要核对准确。

### 二、定义孔属性及预大孔径

edit   Atlributes   点击 "change"弹出窗口：蓝色框住窗口点击"AttributeS"出现下面窗口

#### 一）、一般孔属性定义有三种：

1.Plated(金属孔，不需要定义默认的）；2.non_plated(非金属孔);3.ViA(只是导通作用的金属孔）。

例如：定义via孔，先把需要定义孔属性的选择起来，然后选择VIA,点击ADD添加，Attributes显示红色，点击OK就定义好了，定义非金属孔步骤也一样的。注意：定义孔属性一定要看客户要求结合资料设计，有问题需要提出来与客户确认。

#### 二）、孔径预大一般要求

一般plated预大0.15MM;non_plated一般预大0.05MM；VIA孔一般不做预大

### 四、钻孔检查：

AnalysisDrill Checks

（图中标注：钻孔到Rout的最大距离、需要检测项、检查多孔钻孔类型）

| 检查项 | 说明 |
|---|---|
| Hole Size | 列出各种孔(NPTH、PTH、Via),包括导引孔（pilot drill） |
| Extra Holes | 报告不属于任何Pad的多余孔 |
| Hole Separtion | 报告重复孔、接触孔和闭合孔(close hole) |
| Power/Ground Shorts | 报告与地电层短路的钻孔 |
| Missing holes | 非SMD Pads的缺孔 |
| NPTH to Rout | 报告具有.Tooling_hole，.mount_hole属性的钻孔和靠近成型线的NTPH |

常见报告结果:

1）、Duplicate Holes (Hole Separation)   重叠的孔（比如，同心圆）

<!-- page:117 -->

2）、Touching Holes (Hole Separation)      彼此接触的孔

3）、Close Holes (Hole Separation)      太靠近的孔

4）、Missing Holes (Missing Holes):   缺孔

5）、Extra Holes (Extra Holes):       多孔

6）、NPTH to Rout (NPTH to Rout)   非金属孔距板边距离

### 五、钻孔输出

等资料做好，拼好整个生产panel，就可以输出钻孔，切换到Engineering Toolkit窗口，ActionsAuto Drill Manager（现在工厂一般都是用脚本输出）

### 六、钻孔制作的注意事项

1）检查是否有漏孔漏槽与原稿分孔图对，多次看看客户制作要求；

2）注意短槽的制作（每一个工厂不同要求不一样）；

3）近孔及相交孔制作要求（根据工厂不同要求不同）；

4）注意倒角孔的加法；

5）除披峰及毛刺孔的加法.
